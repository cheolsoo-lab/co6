# 코인 추천 (Bitget 선물용) — 핸드폰에서 보기

파일 4개가 한 세트입니다: `app.py`, `app_logic.py`, `crypto_market_regime.py`, `requirements.txt`

## 방법 A. Streamlit Community Cloud (가장 쉬움, 무료)

1. GitHub에 새 저장소를 만들고 위 파일 4개를 올립니다.
2. https://share.streamlit.io 에서 **New app** → 저장소 선택 → Main file: `app.py` → **Deploy**
3. 나온 주소(`https://○○○.streamlit.app`)를 폰 브라우저로 열고 **홈 화면에 추가**하면 앱처럼 씁니다.

주의할 점
- 서버가 해외(주로 미국)에 있어서 **일부 거래소는 접속이 차단될 수 있습니다.**
  프로그램이 막힌 거래소는 건너뛰고 다음 거래소를 쓰지만, 전부 막히면 화면에 오류가 표시됩니다.
- 앱이 재시작·절전되면 **저장 파일이 초기화**됩니다. 그러면 BTC.D·USDT.D·TOTAL 추세 기록과
  매매 결과 기록이 쌓이지 않아서, 국면 판단이 항상 "BTC 가격 추세 기준"으로만 나옵니다.
- 주소를 아는 사람은 누구나 볼 수 있습니다. **API 키는 어디에도 넣지 마세요** (이 프로그램은 키가 필요 없습니다).

## 방법 B. 내 PC 또는 서버에서 실행 (기록이 계속 쌓임, 권장)

```bash
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0
```

- 같은 Wi-Fi의 폰에서 `http://PC의 IP주소:8501` 로 접속합니다.
- 밖에서도 보려면 PC/서버에 **Tailscale** 같은 사설 VPN을 깔고 폰에서도 연결하는 방법이 안전합니다.
- 24시간 켜둘수록 BTC.D 등 시장 기록이 쌓여서 국면 판단이 정확해집니다.
  (한국 서버라면 거래소 지역 차단 문제도 거의 없습니다.)

## 화면 사용법

- **전체 분석**은 신호 봉이 마감될 때만 자동으로 돌아요 (4시간봉 기준 한국시간 01·05·09·13·17·21시 직후, 1~3분 소요).
- 그 사이에는 **추천 코인의 현재가만** 15~60초마다 자동으로 받아서 상태를 갱신해요 (몇 초).
  - ✅ 진입가 근처 / ⏳ 추격 구간(지정가 대기) / ❌ 무효(손절선을 먼저 넘음) / ⌛ 놓침(목표1에 먼저 도달)
- **총 리스크 상한**: 설정에서 "지금 보유 중인 포지션 수"를 입력하면, 한꺼번에 손절돼도 상한(기본 5%)을 넘지 않는
  만큼만 진입 대상으로 표시해요. 프로그램은 거래소 계좌를 볼 수 없어서 직접 입력해야 정확합니다.
- **청산 계획(v27)**: 목표1(추적 시작)에 닿아도 팔지 않고 손절을 진입가로 → 이후 카드에 적힌 폭만큼 되돌리면 전량 정리.
- **스캔 코인 수**: 3개 거래소 거래량을 합친 순위 상위 N개(기본 60 — 검증에서 60위까지 플러스). 과거 검증의 '거래량 구간별' 결과에서
  플러스가 확인된 구간까지만 늘리세요.
- **추천할 신호 유형**: 기본은 돌파만. 2년 과거 검증(4시간봉)에서 돌파만 뚜렷한 플러스였고, 추세·박스 역매매는
  엣지가 확인되지 않았어요. 설정에서 켤 수는 있어요.
- **1000배 표기 코인**: Bitget 선물이 1000PEPE처럼 표기되는 코인은 카드에 안내가 뜨고, 주문 메모의 가격·수량은
  선물 기준으로 환산돼 있어요.
- **신호 봉**: 기본은 4시간봉. 1시간봉은 비교용이에요(신호가 잦은 대신 가짜 신호와 수수료 비중이 큼).
- 카드의 **📋 주문 메모**를 복사해서 Bitget 주문 화면에 참고하세요.
- 오류가 나면 화면의 오류 내용을 그대로 복사해서 알려주세요.

## 돌파 임박 관찰 · 실전 추천 추적

- **👀 돌파 임박 관찰**: 유효한 박스의 경계에 1 ATR 이내로 붙은 코인 목록이에요. 아직 진입 신호는 아니고,
  봉이 거래량과 함께 경계 밖에서 마감하면 추천으로 올라와요. 현재가가 경계를 넘는 중이면 🔥 표시가 떠요.
  추천이 없는 날에도 미리 알림을 걸어두고 준비할 수 있어요.
- **📈 실전 추천 추적**: 앱이 낸 추천을 '그대로 모두 진입했다면'으로 가정하고, 이후 실제 완성봉으로
  체결·손절·익절 결과를 자동 계산해요(대기 → 보유 → 종료, 또는 미체결). 신호 유형별 최근 30건 성과를
  과거 검증 예상치와 비교해서, 크게 벗어나면 경고해요. 과거가 아니라 지금 시장에서의 성과를 보는 장치예요.
  Streamlit Cloud는 앱이 재시작되면 기록이 지워질 수 있어서, 오래 쌓으려면 내 PC·서버에서 돌리는 게 좋아요.

## ☁️ GitHub Gist 연결 (v25 · 폰에서 기록이 초기화되지 않게)

Streamlit Cloud는 한동안 접속이 없으면 잠들었다가, 다시 깨어날 때 저장 파일을 모두 지워요. 그래서 실전 추적,
연구실 설정(이 설정 적용), 기준선이 초기화돼요. 비공개 Gist에 저장해두면 재시작해도 그대로 유지돼요.

1. **토큰 만들기**: GitHub 로그인 → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings →
   Personal access tokens → **Tokens (classic)** → Generate new token (classic)
   - Note: `crypto-app`, Expiration: 1년 등 원하는 기간
   - 권한(scope)은 **gist 하나만** 체크 → Generate token → 나온 `ghp_...` 값을 복사해 두기(다시 볼 수 없음)
2. **Gist 만들기**: https://gist.github.com 접속 → 파일 이름 `signal_tracking.json`, 내용 `[]` →
   **Create secret gist** → 주소창의 마지막 긴 영문·숫자(예: `https://gist.github.com/아이디/`**`a1b2c3...`**)가 Gist ID
3. **Streamlit Cloud에 넣기**: share.streamlit.io → 앱 오른쪽 ⋮ → Settings → **Secrets** 칸에 아래 두 줄 붙여넣고 Save
   ```
   GITHUB_TOKEN = "ghp_복사한토큰"
   GIST_ID = "복사한GistID"
   ```
4. 앱이 다시 시작되면 ⚙️ 설정 화면에 **"☁️ 기록 저장: GitHub Gist 연결됨"**이 보이면 완료예요.

- 저장 대상: 실전 추적, 연구실 설정·기준선, 거시 검증 결과, 매매 기록, 도미넌스 기록. 바뀌면 최대 1분에 한 번 저장돼요.
- PC 앱에서도 같은 기록을 쓰려면, PC의 앱 폴더에 `.streamlit/secrets.toml` 파일을 만들고 같은 두 줄을 넣으세요.
  실전 추적은 양쪽 기록을 합치고(같은 신호는 더 진행된 상태를 남김), 나머지 파일은 마지막에 저장한 쪽이 남아요.
- 토큰은 Gist 권한만 있어서 거래소·코드와 무관해요. 토큰을 코드나 GitHub 저장소에 올리지 마세요(Secrets에만).
- 비공개(secret) Gist는 검색에 안 나오지만, 주소를 아는 사람은 볼 수 있어요. 저장되는 건 추천 기록뿐이에요.
