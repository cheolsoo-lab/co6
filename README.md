# 코인 추천 (Bitget 선물용) — 핸드폰에서 보기

파일 4개가 한 세트입니다: `app.py`, `app_logic.py`, `crypto_market_regime.py`, `requirements.txt`

## 방법 A. Streamlit Community Cloud (가장 쉬움, 무료)

1. GitHub에 새 저장소를 만들고 위 파일 4개를 올립니다.
2. https://share.streamlit.io 에서 **New app** → 저장소 선택 → Main file: `app.py` → **Deploy**
3. 나온 주소(`https://○○○.streamlit.app`)를 폰 브라우저로 열고 **홈 화면에 추가**하면 앱처럼 씁니다.

주의할 점
- 서버가 해외(주로 미국)에 있어서 **일부 거래소는 접속이 차단될 수 있습니다.**
  프로그램이 막힌 거래소는 건너뛰고 다음 거래소를 쓰지만, 전부 막히면 화면에 오류가 표시됩니다.
- 앱이 재시작·절전되면 **저장 파일이 초기화**됩니다. 그러면 BTC.D·USDT.D·TOTAL 추세 기록과
  매매 결과 기록이 쌓이지 않아서, 국면 판단이 항상 "BTC 가격 추세 기준"으로만 나옵니다.
- 주소를 아는 사람은 누구나 볼 수 있습니다. **API 키는 어디에도 넣지 마세요** (이 프로그램은 키가 필요 없습니다).

## 방법 B. 내 PC 또는 서버에서 실행 (기록이 계속 쌓임, 권장)

```bash
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0
```

- 같은 Wi-Fi의 폰에서 `http://PC의 IP주소:8501` 로 접속합니다.
- 밖에서도 보려면 PC/서버에 **Tailscale** 같은 사설 VPN을 깔고 폰에서도 연결하는 방법이 안전합니다.
- 24시간 켜둘수록 BTC.D 등 시장 기록이 쌓여서 국면 판단이 정확해집니다.
  (한국 서버라면 거래소 지역 차단 문제도 거의 없습니다.)

## 화면 사용법

- **전체 분석**은 신호 봉이 마감될 때만 자동으로 돌아요 (4시간봉 기준 한국시간 01·05·09·13·17·21시 직후, 1~3분 소요).
- 그 사이에는 **추천 코인의 현재가만** 15~60초마다 자동으로 받아서 상태를 갱신해요 (몇 초).
  - ✅ 진입가 근처 / ⏳ 추격 구간(지정가 대기) / ❌ 무효(손절선을 먼저 넘음) / ⌛ 놓침(목표1에 먼저 도달)
- **총 리스크 상한**: 설정에서 "지금 보유 중인 포지션 수"를 입력하면, 한꺼번에 손절돼도 상한(기본 5%)을 넘지 않는
  만큼만 진입 대상으로 표시해요. 프로그램은 거래소 계좌를 볼 수 없어서 직접 입력해야 정확합니다.
- **청산 계획**: 목표1에서 절반 익절 → 남은 절반의 손절을 진입가로 → 이후 카드에 적힌 폭만큼 되돌리면 정리.
- **스캔 코인 수**: 3개 거래소 거래량을 합친 순위 상위 N개(기본 60 — 검증에서 60위까지 플러스). 과거 검증의 '거래량 구간별' 결과에서
  플러스가 확인된 구간까지만 늘리세요.
- **추천할 신호 유형**: 기본은 돌파만. 2년 과거 검증(4시간봉)에서 돌파만 뚜렷한 플러스였고, 추세·박스 역매매는
  엣지가 확인되지 않았어요. 설정에서 켤 수는 있어요.
- **1000배 표기 코인**: Bitget 선물이 1000PEPE처럼 표기되는 코인은 카드에 안내가 뜨고, 주문 메모의 가격·수량은
  선물 기준으로 환산돼 있어요.
- **신호 봉**: 기본은 4시간봉. 1시간봉은 비교용이에요(신호가 잦은 대신 가짜 신호와 수수료 비중이 큼).
- 카드의 **📋 주문 메모**를 복사해서 Bitget 주문 화면에 참고하세요.
- 오류가 나면 화면의 오류 내용을 그대로 복사해서 알려주세요.

## 돌파 임박 관찰 · 실전 추천 추적

- **👀 돌파 임박 관찰**: 유효한 박스의 경계에 1 ATR 이내로 붙은 코인 목록이에요. 아직 진입 신호는 아니고,
  봉이 거래량과 함께 경계 밖에서 마감하면 추천으로 올라와요. 현재가가 경계를 넘는 중이면 🔥 표시가 떠요.
  추천이 없는 날에도 미리 알림을 걸어두고 준비할 수 있어요.
- **📈 실전 추천 추적**: 앱이 낸 추천을 '그대로 모두 진입했다면'으로 가정하고, 이후 실제 완성봉으로
  체결·손절·익절 결과를 자동 계산해요(대기 → 보유 → 종료, 또는 미체결). 신호 유형별 최근 30건 성과를
  과거 검증 예상치와 비교해서, 크게 벗어나면 경고해요. 과거가 아니라 지금 시장에서의 성과를 보는 장치예요.
  Streamlit Cloud는 앱이 재시작되면 기록이 지워질 수 있어서, 오래 쌓으려면 내 PC·서버에서 돌리는 게 좋아요.

  **50일선 위 코인 비율 15%** · 4시간봉 추세 코인 비율 5% · 도미넌스·TOTAL 기록 5%(24시간 이상 쌓였을 때)

- 시장 카드에 🪙 알트 해석(알트 강세장 / BTC 주도 등)과 📏 과거 검증 결과가 함께 표시돼요.

  알트 지수·BTC가 실제로 어떻게 움직였는지 집계해요. 평균 수익 차이 0.3%p 이상, 오른 비율 차이 5%p 이상이어야
  '구분력 있음'으로 판정해요.

매일 10시(4시간봉 마감 1시간 뒤)에 이 화면 하나로 루틴을 끝내도록 모아 둔 화면이에요.

## 2년 정밀 검증 결과와 v18 운용 규칙 (82개 코인, 2024.9~2026.10, 1시간봉 정밀 계산 포함)

- **박스 돌파는 봉 마감 직후 시장가 진입**(기본값). 리테스트 지정가는 실제로는 불리했어요(되돌아와 체결되는
  돌파일수록 실패할 가능성이 높음). 진입이 늦을수록 엣지가 줄어요: 바로 +0.49R → 1시간 +0.31R → 2시간 +0.22R.
  카드에 "신호 후 경과 시간"이 표시되고 2시간이 지나면 경고, 4시간이 지나면 진입 비권장이에요.
- **거시 흐름과 반대 방향 신호 제외**(기본 켜짐): 역방향 진입은 평균 −0.43R(두 구간 모두 마이너스), 걸러내면
  거래당 +0.37R(개발 +0.38 · 확인 +0.36). 일봉 흐름 점수가 +0.25 이상이면 숏, −0.25 이하면 롱을 제외해요.
- **스캔 코인 수 기본 100개**: 거래량 1~100위 모든 구간에서 플러스였어요.
- **새벽 신호(01·05시 마감)가 가장 많고 좋아요.** 아침에 늦게 따라 들어가면 엣지가 대부분 사라지니, 바로 못
  들어가면 건너뛰세요. 낮 신호만 바로 진입하는 수동 운용은 리스크 1% 기준 연 약 +30%(최대 낙폭 약 −21%),
  모든 신호를 봉 마감 직후 진입(자동 매매)하면 연 약 +55%(약 −28%)로 계산됐어요(300달러 시작, 동시 보유 반영).
- **적용하지 않는 것**(검증에서 탈락): ATR 추적선 전환, OBV 매집 표시, 알트 지수 대비 강한 코인 고르기,
  코인베이스 프리미엄, 미리 걸어둔 스탑 주문 진입. 신고점 돌파는 1시간 안에 진입할 때만 플러스라 기본 꺼짐.
- 이 숫자들은 오늘 살아남은 코인만으로 계산해 실제보다 좋게 나왔을 수 있어요. 실전 추적으로 확인하세요.

## 코인 그룹별 분석법 (v19, 2년 검증)

| 그룹 | 쓰는 방법 | 이유 |
|---|---|---|
| BTC | 매매 신호 없음, 거시 판단 지표로만 | 박스 돌파·신고점 돌파 모두 엣지 없음 (2년간 박스 신호 18개) |
| 메이저 15개 | 박스 돌파 + 일봉 추세 포트폴리오 + (자동 매매 시) 신고점 돌파 | 유동성이 커서 추세가 잘 이어짐. 추세 포트폴리오 두 구간 연 +39%·+32% |
| 일반 알트 | 박스 돌파 | 가장 강한 신호(+0.55R/+0.30R). 추세 포트폴리오·신고점 돌파는 불안정 |

- 카드에 메이저·일반 알트 배지가 붙고, 실전 추적에서 그룹별 성과를 따로 볼 수 있어요.

## 거래량 구간 · 유동성 상한 (v21)

- 추천 카드에 거래량 순위 구간(1~30위 / 31~60위 / 61~100위) 배지가 붙고, 실전 추적에 구간별 종료 거래 성과가
  따로 나와요. 구간마다 20건 이상 쌓이면 스캔 코인 수(기본 100개)를 실전 데이터로 다시 판단할 수 있어요.
- 주문 금액이 그 코인 24시간 거래대금의 0.1%를 넘으면 수량을 자동으로 줄이고 카드에 💧 표시가 떠요. 지금
  계좌 규모에선 거의 걸리지 않고, 계좌가 커질 때 작은 코인에서 체결 비용이 검증 가정을 넘지 않게 하는 장치예요.

## 실전 운용 규칙 (카드·주문 메모의 📅 실행 줄)

과거 검증과 똑같이 운용해야 검증 결과가 실전에 재현돼요. 카드와 주문 메모에 아래 규칙이 날짜·값으로 표시돼요.
- **지정가 유효기간**: 대기 신호는 신호 봉 마감 후 15봉(약 2.5일)까지. 그때까지 안 닿으면 주문 취소
- **최대 보유 기한**: 진입 후 60봉(약 10일). 목표1·손절 모두 안 닿으면 그날 정리
- **목표1 이후**: 50% 익절 → 남은 물량 손절을 진입가로 → 거래소 트레일링 주문(활성화 가격 = 목표1, 되돌림 %는 카드에 표시)

## 계좌 배분 · 전체 노출 (오늘의 투자 맨 위)

- 추세 포트폴리오를 켜면 계좌를 "신호 매매"와 "포트폴리오"로 나눠요(설정의 배분 비율, 기본 30%). 신호 매매 수량은
  나머지 계좌 기준으로 계산돼요.
- 오늘 할 일(신규 진입·지정가 대기·포트폴리오 조정·알림) 개수와, 신규 진입 + 포트폴리오를 합친 **전체 노출 배수**,
  신규 진입이 모두 손절될 때의 손실을 보여줘요. 노출이 계좌의 3배를 넘으면 경고해요.

- 일봉 근거로 날마다 다시 계산한 점수라(메인 판정 근거의 약 75%), 시장 카드 판정과 조금 다를 수 있어요.

## 표준 기법 후보 (v17)

- **ATR 추적선 전환(슈퍼트렌드)**: ATR 10·배수 3(트레이딩뷰 기본값). 완성봉으로만 계산해 리페인팅이 없어요. 추적선
  방향이 바뀐 봉에서 시장가 진입, 손절은 추적선(최소 1 ATR), 목표1은 손절폭의 2배, 이후 분할 익절+추적 손절.
  연구실에서 통과하면 신호 유형 "추적선 전환"으로 추천돼요.
- **거래량 흐름(OBV) 매집 표시**: 돌파 직전 30봉의 (상승봉 거래량 − 하락봉 거래량) ÷ 전체 거래량이 +0.1 이상이면
  매집(숏은 −0.1 이하 분산). 박스 돌파에 표시로 붙여 효과를 비교해요.

## 🛡 자동 방어

- 실전 추적 결과를 자동으로 과거 검증 기준선과 비교해서, 신호 유형별로 자동 조치해요(설정에서 끌 수 있음).
  - **⚠️ 주의**: 최근 종료 15건 평균이 기준선 정상 범위 아래 → 그 유형의 권장 리스크를 절반으로 낮춰 수량 계산
  - **⏸ 자동 중지**: 최근 30건까지 정상 범위 아래 → 진입 대상에서 빼고 참고용으로만 표시(추적은 계속)
  - 성과가 범위 안으로 돌아오면 자동 복귀. 좋아졌다고 리스크를 올리는 자동 조치는 없어요.
- 기준선은 전략 연구실을 실행할 때마다 자동 저장돼요. 연구실 결과가 없으면 '최근 평균 −0.3R' 고정 기준을 써요.

## 전략 연구실 (🧪 화면)

- 화면 위쪽에서 **🧪 전략 연구실** → 코인 수(9~30)·기간(1년·2년) 선택 → **▶ 연구실 실행** (4시간봉 30개·2년이면 수 분 이상).
- 미리 정한 후보만 시험해요(v17 기준 9개: 실제 데이터에서 탈락한 표시 5개는 제외).
  - 진입 방식: 돌파 즉시 진입, 신고점 돌파(약 20일)
  - 포트폴리오: 추세 포트폴리오(매일 조정·롱, 수수료·슬리피지·롱 펀딩비 차감)
  - 표시: 변동성 수축, 일봉 방향 일치, 알트 지수 대비 강함, BTC 대비 강함, 강한 마감
- 과거의 앞 2/3(개발 구간)에서 비교하고 뒤 1/3(확인 구간)에서 확인해요. 거래량 구간 일관성, 상위 5건 의존도,
  시험 후보 수만큼 할인한 우연 확률까지 모두 통과해야 **✅ 통과**예요.
- 통과한 후보가 있으면 **✔ 이 설정 적용**으로 추천에 반영돼요(설정의 '연구실 설정 초기화'로 되돌릴 수 있음).
  Streamlit Cloud에서는 앱이 재시작되면 저장된 설정이 지워질 수 있어요.
- **📋 복사용** 탭 내용을 보내주시면 결과를 해석해 드려요.
- 비용은 지정가 진입·목표1 익절은 메이커 수수료, 시장가 진입·손절은 테이커 수수료 + 거래량 구간별 슬리피지로 계산해요.
